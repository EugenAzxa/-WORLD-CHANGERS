# World Changers Summits — новый сайт

Новая версия сайта [wcsiasc.org](https://wcsiasc.org) (World Changers Summits, IASC).
Весь контент старого WordPress-сайта перенесён и связан между собой, а в центре — **интерактивный 3D-глобус**: где прошли саммиты, что там происходило, кто выступал.

## Что внутри

Плюс: поиск по всему сайту (кнопка 🔍 или `⌘K` / `/`), `sitemap.xml`, `robots.txt`, OpenGraph-превью, адаптив под телефон.

**Все старые URL сохранены** — ссылки из Google и соцсетей продолжат работать.

## Дизайн

Редакционный стиль Swiss Modernism: светлая «бумага», чернильный текст, один акцент (зелёный IASC), тонкие линейки вместо карточек, нумерованные разделы, шрифты Newsreader / Public Sans / IBM Plex Mono. Глобус оформлен как атлас.
Правила и токены: [design-system/MASTER.md](design-system/MASTER.md), реализация — `src/styles/tokens.css` (primitive → semantic → component) и `src/styles/global.css`.

## Технологии

- [Astro](https://astro.build) 7 — статическая генерация (414 страниц, сборка ~10 сек).
- Глобус — свой canvas-рендер на `d3-geo` + `world-atlas` (без тяжёлого three.js; JS глобуса ≈ 34 КБ).
- Без CMS и сервера: сайт — это папка `dist/`, её можно положить на любой хостинг (Vercel, Netlify, GitHub Pages, Cloudflare Pages, nginx).

## Команды

```bash
npm install
npm run dev        # локально: http://localhost:4321
npm run build      # сборка в dist/
node scripts/check-links.mjs   # проверка всех внутренних ссылок после сборки
```

## Как устроен контент

```
scripts/crawl.sh      — скачивает старый сайт (REST API WordPress + HTML всех страниц из sitemap)
scripts/extract.mjs   — превращает Elementor-разметку в чистый JSON (src/data/*.json)
scripts/media.mjs     — скачивает все картинки, конвертирует в WebP (полный размер + превью) → public/media/
src/data/geo.json     — координаты городов для глобуса и привязка площадок/событий к городам (редактируется вручную)
src/lib/data.ts       — связывает всё: события ↔ места ↔ люди ↔ награды ↔ галереи
```

Обновить контент со старого сайта:

```bash
sh scripts/crawl.sh /tmp/wcs-crawl
node scripts/extract.mjs /tmp/wcs-crawl
node scripts/media.mjs
npm run build
```

Новое событие в новом городе: добавить город в `places` и площадку в `venues` в `src/data/geo.json` — точка появится на глобусе автоматически.
